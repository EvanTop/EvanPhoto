

# EvanPhoto

**EvanPhoto** — 极简沉浸式画廊主题。为纯视觉叙事而生。零冗余元素，让每一张照片都成为页面的绝对主角。可作为独立站点运行，也能作为专属相册或作品集展区。

- 当前版本：2.4.0
- 作者：Evan（<https://evan.xin>）
- 许可：MIT
- Text Domain：`evanphoto`

## 特性

- **沉浸式黑色画廊**：全黑背景、3:2 缩略图网格 + Hero 展示卡，最大化突出照片本身。
- **图片管理（自定义文章类型）**：内置 `evanphoto_photo` 文章类型，后台可集中管理全部图片。
- **双来源支持**：图片既可上传到媒体库（attachment），也可直接填写外链 URL（external）。
- **大图灯箱**：点击缩略图打开沉浸式大图弹窗，支持上一张/下一张导航、键盘方向键、触屏滑动、底部缩略图条与浏览器前进/后退。
- **优雅的图片 URL**：每张图片拥有 `/p/{id}` 独立地址，可直接分享、刷新直达、深链接。
- **EXIF 信息展示**：自动提取相机、拍摄时间、焦距、光圈、快门、ISO 等 EXIF 子集，在灯箱底部展示。
- **分享卡片**：Canvas 实时生成带照片缩略图、品牌名与二维码的分享图片（400×500），可一键保存 PNG。
- **移动端添加图片**：登录用户可在移动端通过浮动“+”按钮上传图片或提交 URL，支持上传进度、EXIF 方向校正与自动转 WebP。
- **图片自动处理**：上传时自动应用 EXIF 方向校正、最长边缩放至 ≤1280px、转存 WebP（质量 82），竖图保持竖图比例。
- **相册分组（可选）**：内置 `evanphoto_album` 分层分类法，默认关闭，可在自定义器中一键启用，前台支持按相册筛选。
- **分页浏览**：每页缩略图数量与页码窗口大小均可配置，支持大图库分页展示。
- **可配置 Hero 区域**：标题、描述、按钮文字/链接、背景图均可通过自定义器调整。
- **统计代码接入**：内置 Umami 统计脚本输出（仅需填入 Website ID）。
- **一次性数据导入**：首次激活时自动从 `data/images.json` 导入历史 Cloudinary 图片清单（仅一次，可在后台删除数据后继续正常使用）。

## 安装方法

1. 下载或克隆本仓库，将 `evanphoto_v3/` 目录上传到 `wp-content/themes/`。
2. 在 WordPress 后台「外观 → 主题」中启用 **EvanPhoto**。
3. 启用后主题会自动刷新重写规则（`/p/{id}` 链接）。若图片 URL 不生效，请到「设置 → 固定链接」点击一次「保存更改」。
4. 进入后台菜单「图片」，开始添加照片：
   - **媒体库方式**：新建图片 → 来源类型选「上传到媒体库」→ 选择/上传图片 → 保存。
   - **外链方式**：来源类型选「外链图片」→ 填写图片 URL（jpg/png/webp/gif 等）→ 保存。
   - 保存后图片会立即出现在首页画廊第一页（按添加时间优先）。

## 使用说明

### 浏览画廊

- 首页以响应式网格展示缩略图（3:2），点击缩略图打开大图灯箱。
- 灯箱内：`←` / `→` 按钮切换图片；键盘 `←` / `→` 切换、`Esc` 关闭；移动端可左右滑动。
- 灯箱底部缩略图条可快速跳转，底部 EXIF 栏展示拍摄参数（如有）。
- 每张图片有独立地址 `/p/{id}`，可直接复制链接分享；浏览器前进/后退会同步灯箱状态。

### 移动端添加图片

1. 以登录用户身份在移动端打开站点（前台自动隐藏管理员工具条）。
2. 点击右下角浮动 `+` 按钮。
3. 选择「上传」并选取本地图片，或切换「URL」粘贴图片地址；可填写标题。
4. 提交后自动完成方向校正、压缩转 WebP，刷新后出现在画廊中。

> 移动端上传通过 `evanphoto/v1/photo` REST API 完成，需要登录且具备 `upload_files` 权限；桌面端建议直接使用后台「图片」菜单管理。

### 相册分组（可选）

1. 打开「外观 → 自定义 → EvanPhoto」，勾选「启用相册分组功能」。
2. 后台「图片 → 相册」中创建相册，并在编辑图片时归属到对应相册。
3. 前台画廊顶部会出现相册筛选条，可一键按相册过滤。

### 分享卡片

- 首页 Hero 卡左上角与灯箱内均有分享按钮（Hero 分享按钮需在自定义器中填写「首页分享按钮链接」后才会显示）。
- 点击后生成分享卡片：照片缩略图 + 品牌名 + 二维码 + 标题/域名，可保存为 PNG。

## 数据导入说明（data/images.json）

`data/images.json` 是主题早期从 Cloudinary（`res.cloudinary.com/zeit-inc/image/upload/...`）迁移图片时使用的导入清单，共 20 条记录。主题在首次激活时读取一次并写入对应 `evanphoto_photo` 文章，随后通过选项 `evanphoto_imported_v1` 标记跳过，**不会重复导入**。

- 该文件仅为历史数据，新站点可在导入后安全删除。
- 清单内图片素材来自第三方 CDN 历史内容，开源发布前请自行确认素材版权。**建议**删除本文件或替换为自己的图片数据后发布，避免随仓库携带未经授权的图片 URL 与占位数据。

## 常见问题

**Q：图片 URL `/p/1` 打开 404？**
A：在「设置 → 固定链接」页面点击「保存更改」以刷新重写规则；或重新启用主题（主题已注册 `after_switch_theme` 刷新）。

**Q：上传图片提示 GD/WebP 不支持？**
A：主题依赖 PHP GD 扩展且需编译了 WebP 支持。请安装 `php-gd`（含 WebP）后重启 PHP-FPM。

**Q：外链图片不显示？**
A：外链图片直接以原 URL 展示，请确认图片地址可公开访问；尺寸缓存依赖 PHP `allow_url_fopen` 与 `getimagesize`，无法获取时仅影响竖图判断，不影响展示。

**Q：启用相册后前台没有筛选条？**
A：相册筛选条只在「已启用相册 + 已有照片归属到相册」时出现。
